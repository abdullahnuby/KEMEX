# Sprint 02 — بطاقة الأصل

## النطاق المنفذ
- أضيفت `AssetDetailPage.tsx` كصفحة مستقلة تستقبل معرف الأصل من المسار `asset/:id`.
- أصبح زر العرض من جدول الأصول يفتح بطاقة الأصل بدل نافذة عرض مختصرة.
- تحتوي البطاقة على ملخص الأصل والبيانات الأساسية، وتبويبات التخصيصات والتشغيل والوقود والصيانة والإطارات والتكاليف وسجل التدقيق.
- رُبطت البيانات المتاحة من الحالة الحالية، مع رسائل فارغة عند غياب سجلات مرتبطة.
- أضيف زر للعودة إلى سجل الأصول ورابط إلى وحدة الصيانة.

## ملاحظات وحدود
- لم يتم إنشاء عمليات CRUD جديدة لسجلات التبويبات؛ العرض يستخدم بيانات المستودع المحملة بالفعل.
- زر تعديل الأصل يعود إلى سجل الأصول ولا يفتح النموذج مباشرة حتى الآن.
- يلزم التحقق من أسماء حقول الربط في بيانات الإطارات والتكاليف والتدقيق، ومن سلوك التبويبات أمام قاعدة بيانات فعلية.
- لا يمكن اعتماد نجاح TypeScript أو البناء في هذه البيئة؛ `npm run typecheck` توقف بسبب عدم تثبيت React وVite وبقية الحزم، وتبقى أخطاء الأنواع الظاهرة غير قابلة للحسم قبل تثبيت الاعتماديات.

## تحقق
- `node scripts/verify-source.mjs`: ناجح، وحافظ على بيانات العرض التجريبية.
- `npm run typecheck`: غير مكتمل بسبب اعتماديات مفقودة.
