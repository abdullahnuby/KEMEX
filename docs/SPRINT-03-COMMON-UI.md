# Sprint 03 — تحسينات الواجهة المشتركة

## ما تم تغييره
- مزامنة رقم الإصدار الظاهر في واجهة التطبيق مع إصدار الحزمة `0.11.0`.
- إضافة أسماء وصول واضحة لأزرار فتح/إغلاق/طي/توسيع القائمة الجانبية، ولزر التنبيهات وأزرار تعديل/حذف السجلات.
- إضافة حالة `aria-pressed` لمرشحات الحالة حتى تعلن حالة الاختيار للتقنيات المساعدة.
- توحيد شكل حقول النص متعددة الأسطر مع بقية حقول النماذج.
- إضافة مؤشر تركيز مرئي للتنقل بلوحة المفاتيح.
- تحسين تمرير الجداول أفقيًا على الشاشات الصغيرة ومنع ضغط أعمدة الجدول بشكل غير مقروء.
- ترتيب أزرار إجراءات الصفحة على الشاشات الصغيرة.

## حدود هذا السبرنت
- هذه تحسينات واجهة مشتركة وليست إثباتًا لاختبار كل نموذج أو عملية CRUD.
- لم يتغير منطق قواعد البيانات أو صلاحياتها.
- لم يتم اعتماد البناء النهائي؛ يلزم تثبيت الحزم أولًا ثم تشغيل `npm run typecheck` و`npm run build`.
