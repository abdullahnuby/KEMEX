# حالة تحويل TFMS

## ما تم تنفيذه في Foundation v0.1

- تحويل الواجهة من HTML/JavaScript أحادي الصفحة إلى React + TypeScript.
- تصميم RTL جديد وأخف بصريًا باستخدام Lucide بدل الاعتماد على الرموز التعبيرية في التنقل.
- تسجيل دخول Demo محلي مع حفظ الجلسة.
- طبقة Repository واحدة تسمح بالعمل Demo محليًا أو Supabase عند ضبط البيئة.
- لوحة المعلومات الأساسية.
- قائمة الأصول مع البحث والتصفية وبطاقة التفاصيل وتعديل البيانات في Demo.
- المشروعات.
- أوامر الصيانة.
- الوقود.
- هيكل تنقل كامل لكل وحدات النسخة الحالية مع بوابات انتقال مؤقتة للوحدات التي لم تُرحّل بعد.
- PostgreSQL schema مبدئي مع RLS وrole helper في schema خاصة.
- نقل بيانات النسخة الحالية إلى `src/data/demoSeed.json`.
- `supabase/seed.sql` يحافظ على بيانات Demo الحالية؛ الوحدات غير المرحّلة إلى جداول Typed تُحفظ مؤقتًا في `tfms_module_records`.
- النسخة الأصلية المصححة محفوظة في `legacy/TFMS_Fixed.html` للرجوع والمطابقة أثناء النقل.

## البيانات التي تم الحفاظ عليها من النسخة الحالية

- 6 مشروعات.
- 20 أصلًا.
- 5 عقود.
- 8 سائقين/مشغلين.
- 208 سجلات تشغيل.
- 9 أوامر عمل.
- 156 حركة وقود.
- باقي Collections الأصلية محفوظة داخل ملف Demo وتُرحّل إلى `tfms_module_records` في seed.
