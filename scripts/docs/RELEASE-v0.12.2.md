# TFMS Web v0.12.2 — Sprint 07-03/04

## نطاق الدفعة
استكمال المالية والإدارة وربط إعدادات المؤسسة بسلوك النظام.

## التعديلات
- شاشات متخصصة للتكاليف والإهلاك والتحميل الداخلي والفواتير والعملاء وسجل التدقيق.
- تطبيق مصفوفة الوصول حسب الدور على القائمة وعلى المسارات المباشرة.
- ربط ضريبة المؤسسة بحساب الفواتير الجديدة.
- ربط أسعار الوقود الافتراضية بإعدادات المؤسسة.
- ربط نافذة التنبيه الزمنية بإعدادات المؤسسة.
- تحديث الإعدادات ينعكس فورًا على الواجهة الحالية.
- تسجيل منفذ التدقيق المحلي وفق المستخدم الحالي.

## الاختبارات
تنفيذ اختبارات التطبيق والبناء وSupabase/RLS مؤجل بطلب المستخدم إلى مرحلة الاختبارات النهائية.
