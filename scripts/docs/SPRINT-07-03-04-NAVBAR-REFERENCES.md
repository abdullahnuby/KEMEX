# Sprint 07-03/04 — الإدارة، المالية، Navbar ومرجعيات الأسماء

## نطاق الدفعة
- إكمال وحدات الإدارة والمالية التشغيلية المخططة في Sprint 07.
- استبدال Sidebar بشريط Navbar علوي متجاوب مع قوائم منسدلة.
- إضافة طبقة Reference Resolver موحدة لمنع عرض معرفات الأصول والمشروعات والعملاء والعقود وغيرها كقيم خام في الجداول والنماذج.
- إضافة عقود الإيجار إلى التنقل المرئي بما يتوافق مع مصفوفة الصلاحيات المرجعية.
- مواءمة حسابات التكاليف والتحويل الداخلي والضريبة والتنبيهات مع منطق المرجع حيث يدعم المصدر ذلك.

## قواعد العرض
الاسم البشري هو القيمة الأساسية في الواجهة، ويظهر الكود/الرقم كمرجع ثانوي. عند عدم وجود سجل مطابق فقط تُعرض القيمة الخام لضمان عدم فقدان البيانات.

## الاختبارات
اختبارات typecheck/build وSupabase/RLS والمتصفح مؤجلة بناءً على طلب المستخدم. فحص سلامة المصدر والأرشيف فقط يتم قبل التسليم.
