# TFMS Web v0.11.6 — Sprint 06-02

## ما تم تنفيذه
- صفحة متخصصة لخطط الصيانة الوقائية وحساب الاستحقاق حسب نوع العداد أو الأيام.
- إنشاء أمر عمل مباشرة من خطة صيانة مستحقة مع ربطه بالخطة.
- دورة حالة متخصصة لأوامر العمل: اعتماد الفتح، بدء التنفيذ، انتظار قطع الغيار، ثم الإنجاز وتسجيل التكاليف ونتائج الفحص.
- صفحة متخصصة للمخزون وقطع الغيار تعرض الرصيد والحد الأدنى وقيمة الرصيد.
- صرف مخزني يتحقق من الرصيد ويسجل حركة الصرف وربطها بالأصل وأمر العمل والمشروع.
- إنشاء طلب شراء من صنف تحت الحد الأدنى دون تنفيذ شراء مباشرة.
- إصلاح ربط بيانات Demo المحلية مع أسماء الوحدات المستخدمة في React.
- تحديث الإصدار إلى 0.11.6.

## التحقق
- `node scripts/verify-source.mjs` — **ناجح**.
- أعداد البيانات الأساسية وبيانات Sprint 06-02 متحققة من مصدر Demo.
- وجود الصفحات والمسارات المتخصصة متحقق منه آليًا.
- `npm install` — **لم يكتمل** بسبب تجاوز المهلة مرتين.
- `npm run typecheck` — **غير متحقق**.
- `npm run build` — **غير متحقق**.
- بيئة التنفيذ Node 22، بينما المشروع يتطلب Node 24+.

## ملاحظات أمان/ذرية البيانات
- المسار المتخصص لا يتجاوز صلاحيات الكتابة الموجودة في التطبيق.
- على Supabase، تحديث رصيد المخزون وإنشاء حركة الصرف يحتاجان Transaction/RPC نهائيًا لضمان الذرية؛ هذا لم يُنفذ في هذه الدفعة.

## المرجع
`legacy/TFMS_Fixed.html` هو المرجع الوظيفي والتصميمي المستخدم لهذه الدفعة.
