# KEMEX v0.33.0 — Final Workspace Navigation

## الهدف
تحويل شريط التنقل من قائمة طويلة من الصفحات إلى مساحات عمل قليلة وواضحة، مع الحفاظ على المسارات الداخلية والروابط القديمة.

## الشكل النهائي
- الرئيسية + الجرس للتنبيهات.
- التشغيل.
- الأسطول والصيانة.
- المخزون والمالية.
- التقارير والإدارة.

## داخل كل مساحة
تمت إضافة عناوين فرعية داخل القوائم المنسدلة لتجميع الوظائف المتقاربة بدل عرضها ككتلة واحدة.

## المسارات القديمة
- `movements` يظل مدخلًا قديمًا إلى `inventory`.
- `trips/dispatch` يظل مدخلًا قديمًا إلى `trips`.
- `reports/true-cost` يظل مدخلًا قديمًا إلى `true-cost`.
- بطاقة التكلفة الحقيقية أصبحت قابلة للوصول من مركز التقارير دون إضافة مدخل رئيسي جديد.

## قاعدة UX
الصفحة التفصيلية لسجل معين ليست عنصرًا مستقلًا في القائمة؛ تُفتح من السجل الأب، مثل تفاصيل الأصل أو المشروع أو الرحلة أو العطل.
