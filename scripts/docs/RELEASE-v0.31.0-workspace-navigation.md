# KEMEX v0.31.0 — تنظيم مساحات العمل

## الهدف
تقليل العبء الذهني في التنقل عبر تجميع الوحدات في مجالات عمل واضحة، مع عدم دمج جداول أو عمليات مختلفة على مستوى البيانات.

## التغييرات
- تحديث مجموعات القائمة إلى: الرئيسية، البيانات الأساسية، التشغيل، الصيانة والأعطال، المخزون والمشتريات، المالية، الإدارة والتقارير.
- جعل تمييز المجموعة النشطة يعتمد على الوحدة المالكة للمسار؛ لذلك تظل مجموعة الأصل/المشروع/العطل/الرحلة/التخصيص محددة عند فتح صفحة تفصيلية أو إجراء فرعي.
- تحديث إصدار التطبيق إلى 0.31.0.

## حدود هذه النسخة
هذه إعادة تنظيم للتنقل فقط. لم يتم دمج شاشات CRUD أو تغيير مخطط قاعدة البيانات أو سياسات RLS. يلزم اختبار الصلاحيات والتنقل والبناء قبل النشر.
