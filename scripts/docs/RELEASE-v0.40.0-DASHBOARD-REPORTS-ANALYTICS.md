# KEMEX v0.40.0 — Dashboard & Reports Analytics Overhaul

## هدف الإصدار
إعادة تصميم لوحة المعلومات ومركز التقارير كواجهات تحليلية فعلية بدل شاشات عرض ثابتة.

## لوحة المعلومات
- إضافة اتجاه شهري للتكلفة والوقود لآخر 6 أشهر من البيانات المتاحة.
- إضافة توزيع دائري لحالة الأسطول.
- إضافة تحليل الأصول حسب المشروع.
- إضافة مقارنة ساعات التشغيل والتوقف.
- تحسين مؤشرات التشغيل والتنبيهات.

## مركز التقارير
- إزالة دورة: اختيار التقرير ← النزول ← تشغيل التقرير.
- تحديث التقرير والنتيجة مباشرة عند تغيير الاختيار أو المرشحات.
- وضع اختيار التقارير والمرشحات داخل Workbench واحد.
- إضافة تحليل بصري رئيسي لكل تقرير مبني على بيانات التقرير الناتجة.
- إضافة KPIs ديناميكية وStatus distribution عند توفرها.
- إبقاء التصدير والطباعة والـTrue Cost.

## قيود التحقق
تم إجراء TypeScript/JSX transpile للملفات المعدلة ونجح، كما نجح source integrity check.
الإنتاج الكامل يحتاج بيئة dependencies كاملة وNode 24 لتشغيل `npm ci` ثم `npm run build`.
