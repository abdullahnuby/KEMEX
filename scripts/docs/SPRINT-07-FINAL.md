# Sprint 07 — Final Development Package v0.13.0

تم إكمال نطاق Sprint 07 التطويري قبل مرحلة الاختبارات النهائية.

## الإدارة والمالية
- التكاليف والإهلاك.
- التحميل الداخلي.
- الفواتير والمستحقات.
- العملاء.
- سجل التدقيق.
- الإعدادات ومصفوفة الصلاحيات.

## التقارير
- مركز تقارير موحد بعشرة تقارير.
- مرشحات الفترة والفئة والملكية والحالة والمشروع.
- تصدير CSV عربي وطباعة.

## الواجهة والتنقل
- استبدال Sidebar بـ Navbar علوي متجاوب.
- قوائم منسدلة حسب مجموعات النظام.
- بحث في التنقل للموبايل.
- الحفاظ على RTL وهوية TFMS.

## المرجعيات
Reference Resolver مركزي يعرض الاسم البشري أولًا، والكود/الرقم كمرجع ثانوي، ويستخدم في الجداول والنماذج والتفاصيل والتقارير الموحدة حيث تتوفر بيانات المرجع.

## الاختبارات
تم تأجيل typecheck/build، اختبار المتصفح، Supabase/RLS والاختبارات التشغيلية إلى مرحلة الاختبارات النهائية حسب توجيه المستخدم.
