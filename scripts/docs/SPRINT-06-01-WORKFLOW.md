# Sprint 06-01 — دورة التشغيل والاعتماد

## النطاق
تثبيت دورة الاعتماد الأساسية في الوحدات التي كانت في المرجع تعمل بأزرار انتقال حالة، بدل الاعتماد على حقل حالة حر داخل CRUD العام.

## المنفذ
- طلبات المعدات: مسودة → بانتظار اعتماد مدير المشروع → معتمد من مدير المشروع / معاد للتعديل / مرفوض → قيد التنفيذ → مكتمل.
- التخصيصات: ساري → منتهي. عند الإنهاء يُعاد الأصل إلى متاح ويُغلق الطلب المرتبط عند وجود الربط.
- التشغيل اليومي: مسودة/معادة → مقدمة → معتمد، أو إعادة للمقدم. عند الاعتماد يُحدّث عداد الأصل إذا كانت القراءة الجديدة أعلى.
- الرحلات: بانتظار الاعتماد → مكتملة.
- المشتريات: قيد الاعتماد → معتمد / مرفوض → أمر شراء، مع توليد رقم أمر شراء عند الحاجة.

## الصلاحيات
تم تضييق الكتابة على الوحدات المتأثرة لتتبع مصفوفة الصلاحيات الموجودة في المرجع الأصلي قدر الإمكان. أزرار الاعتماد لا تظهر إلا عندما يكون دور المستخدم موجودًا في تعريف الإجراء والحالة الحالية تسمح به.

## التحقق
`node scripts/verify-source.mjs` ناجح. لم يتم تشغيل typecheck/build لأن بيئة التنفيذ الحالية Node 22 بينما `package.json` يحدد Node 24+، ومحاولات تثبيت الاعتماديات انتهت بمهلة.
