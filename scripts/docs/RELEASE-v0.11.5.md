# TFMS Web v0.11.5 — Sprint 06-01

## تنفيذ Sprint 06-01
- دورة طلبات المعدات أصبحت: مسودة → بانتظار اعتماد مدير المشروع → معتمد من مدير المشروع / معاد للتعديل / مرفوض → قيد التنفيذ → مكتمل.
- من الطلب المعتمد يمكن تنفيذ «تخصيص أصل» عبر نموذج مستقل مرتبط برقم الطلب.
- نموذج التخصيص يقتصر على الأصول المتاحة أو المحجوزة، ويسجل عداد التسليم وبداية ومدة التخصيص.
- حفظ التخصيص يحدّث الأصل إلى حالة العمل المناسبة ويربط التخصيص بالطلب، ثم يحوّل الطلب إلى «قيد التنفيذ».
- إنهاء التخصيص يعيد الأصل إلى «متاح» ويغلق الطلب المرتبط عند وجود الربط.
- التشغيل اليومي يدعم تقديم/اعتماد/إعادة، واعتماد السجل يحدّث عداد الأصل عند الحاجة.
- الرحلات تدعم اعتماد الرحلة من الحالة المعلقة.
- المشتريات تدعم الاعتماد/الرفض وإصدار أمر شراء.
- حالات الوحدات ذات التدفق لا يمكن تعديلها مباشرة داخل نموذج CRUD؛ تنتقل عبر أزرار الإجراءات.
- تم تضييق صلاحيات الكتابة للوحدات المتأثرة بما يتوافق مع مصفوفة الأدوار في المرجع قدر الإمكان.

## التحقق الفعلي
- `node scripts/verify-source.mjs` — **ناجح**.
- Structural/static checks للملفات المعدلة — **ناجحة**.
- تم التأكد من توازن البنى الأساسية في ملفات TypeScript المعدلة.
- `npm run typecheck` — **لم يُشغّل بنجاح** لأن الاعتماديات غير مثبتة.
- `npm run build` — **لم يُتحقق منه** للسبب نفسه.
- بيئة التنفيذ الحالية تستخدم Node 22، بينما المشروع يحدد Node 24+.
- محاولة `npm install` انتهت بمهلة، لذلك لا توجد مصادقة على build إنتاجي حتى الآن.
