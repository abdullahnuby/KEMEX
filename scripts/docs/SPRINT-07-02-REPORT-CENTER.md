# Sprint 07-02 — مركز التقارير المرجعي (v0.12.1)

تم توسيع مركز التقارير React ليطابق مجموعة التقارير الأساسية الموجودة في `legacy/TFMS_Fixed.html` بدل نموذج التقارير المختصر.

## نطاق الدفعة
- التقرير الشامل لجميع الأصول.
- الأصول المملوكة والإهلاك والقيمة الدفترية.
- الأصول المستأجرة والعقود.
- السيارات والمركبات مع الاستهلاك.
- المعدات والمولدات مع تكلفة الساعة.
- عقود الإيجار.
- الاستحقاقات للصيانة والزيوت.
- الوقود: الاستهلاك والتكلفة.
- المخزون وقطع الغيار.
- الموافقات المعلقة.
- مرشحات: من، إلى، الفئة، الملكية، حالة الأصل، المشروع.
- تشغيل التقرير قبل اعتماده للتصدير.
- تصدير CSV مع BOM لفتح العربية في Excel.
- طباعة التقرير.

## ملاحظة التحقق
تم تنفيذ الدفعة على مستوى المصدر فقط كما طلب المستخدم؛ اختبارات التشغيل و`typecheck` و`build` مؤجلة ولم تُستخدم لإغلاق الدفعة.
